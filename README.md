# 🎓 Student AI Prompt Toolkit

A curated collection of AI prompts designed to help students study smarter, save time, and improve productivity using Generative AI.

## 📌 Project Overview

This repository contains high-quality prompts for common student tasks such as note summarization, quiz generation, assignment writing, study planning, flashcard creation, exam preparation, and more.

## ✨ Features

- 📚 Notes Summarizer
- 📝 Quiz Generator
- 📄 Assignment Writer
- 📅 Study Planner
- 🧠 Flashcard Generator
- 🎯 Exam Preparation Assistant
- ❓ Doubt Solver
- 📊 Presentation Creator
- 🔍 Research Assistant
