# 🎓 Student AI Prompt Toolkit

A curated collection of AI prompts designed to help students study smarter, improve productivity, and simplify learning using Generative AI and Prompt Engineering.

---

## 📖 Project Overview

Student AI Prompt Toolkit is a collection of well-structured prompts created for students. These prompts help users summarize notes, generate quizzes, write assignments, prepare for exams, create flashcards, and perform many other academic tasks with the help of AI.

The project is designed to save time, improve learning efficiency, and demonstrate practical Prompt Engineering techniques.
